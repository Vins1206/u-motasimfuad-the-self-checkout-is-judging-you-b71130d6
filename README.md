One funny line in the voice of a smug self-checkout machine, for the
[make.fun bounty](https://make.fun/bounty/u-motasimfuad-the-self-checkout-is-judging-you-b71130d6).

The entry:

> You weighed the grapes, then ate three. I counted. I am literally a scale with opinions.

## How to run

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` is pure Python stdlib. It writes exactly one line (88 characters)
to `/output/entry.txt`, inside the 1–200 character gate.

## How the line was picked

Eight hand-written candidates were scored on surprise, specificity,
relatable embarrassment, machine voice, tightness, and freshness.
The grape line won: weighing is the machine's own job, eating three
grapes mid-weigh is a small crime everyone recognises, and
"I am literally a scale with opinions" is the till talking, not a
narrator describing it. It avoids the yoghurt example from the brief
and the "unexpected item in the bagging area" cliché, which the judge
has heard a thousand times.
